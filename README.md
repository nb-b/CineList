# Aplikasi Data Film Favorit

### Deskripsi
Aplikasi untuk menyimpan dan mengelola daftar film favorit menggunakan struktur data
linked list.

Program menyediakan fitur:
- tambah data film,
- tampil daftar film,
- pencarian film,
- pengurutan data film,
- edit data film,
- dan hapus data film.

Data film dapat meliputi:
- kode film,
- judul film,
- genre,
- tahun rilis,
- rating,
- dan nama sutradara

### Pembagian Tugas Anggota
**Anggota 1: Struktur Data dan Input Film**
Tugas:
- Membuat struktur node linked list.
- Membuat fungsi tambah data film.
- Membuat input data film.
- Mengelola pointer head dan node.

**Anggota 2: Pencarian dan Pengurutan Film**
Tugas:
- Membuat fitur pencarian film berdasarkan judul/genre.
- Membuat fitur sorting/pengurutan data film.
- Membuat validasi input data.
- Membuat menu program.

**Anggota 3: Tampilan dan Manipulasi Data**
Tugas:
- Membuat tampilan daftar film favorit.
- Membuat fitur edit dan hapus data film.
- Membuat tampilan output program yang rapi dan menarik.
- Membuat laporan sederhana daftar film.
